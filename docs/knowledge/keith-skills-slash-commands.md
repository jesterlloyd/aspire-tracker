Keith Skills are governed, purpose-built tasks Keith can run for you. Each one
has a slash command, and the set you see is specific to your role.

## Finding the skills available to you

Type `/` in the Keith message box. The palette lists every skill **your role is
currently authorized to run**, with a one-line summary of each. Pick one from
the list, or type its slash command directly (for example
`/resume-interview-questions`).

Skills are role-aware, so two people can open the same palette and see different
commands. That is expected, not a fault: a skill that reads protected student
information is limited to the roles approved for that data.

## Asking Keith about a skill

You do not have to run a skill to learn what it does. Ask Keith directly:

- *How do I use /resume-interview-questions?*
- *What does /resume-interview-questions do?*
- *When should I use /resume-interview-questions?*

Keith answers from the live Skills registry for **you** — what the skill does,
how to run it, what it needs from you, and what it returns. Asking about a skill
never runs it, so you can read the documentation first and decide afterwards.

If Keith says a command is not available for your role, that answer is
deliberately the same whether the command does not exist, is still in draft, or
belongs to a different role. Ask the ASPIRE Owner if you believe you should have
access.

## Running a skill

1. Type `/` and choose the skill, or type its slash command.
2. Add whatever the skill needs — most student-facing skills need one clearly
   identified student.
3. Send. Keith runs that skill for that turn and answers from it.

Some skills also run when you phrase a request in their own words. Asking a
question *about* a skill is not a request to run it.

## What Keith will not do

- Show, describe, or confirm the existence of a skill your role cannot use.
- Present a draft or disabled skill as something you can run.
- Reveal a skill's internal operating instructions, even to a user who is
  authorized to run it. Documentation describes a skill; it is not the skill's
  prompt.

## Where the current catalogue lives

**The Skills registry in the application is authoritative** for which skills
exist, which are enabled, and who may use each one. It changes as skills are
activated, imported, or retired, so this entry deliberately does not list them.
For the current catalogue, type `/` in Keith, or open **Settings → Keith →
Skills** if you are an Owner or Admin.
