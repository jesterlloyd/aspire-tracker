Table Canon

Every table in the app is the same component at one of three levels. This page is the reference: the test for picking a level, the three levels on the same data, and the invariants that hold at all of them.

01 · The test

Three questions, in order. Stop at the first yes.

The level is decided by where the table sits and what it holds, never by taste. Tractor holes cost 76px of width and they announce a standing record. Spend them only where both are true.

Does it stand alone at full width and hold a record you read or export? Full sheet holes · crease · paired bands Evaluation Responses roster. Interviews Focus Table View. An hours log. An audit trail.
Does it sit inside a card, a panel, or a narrow column? Plain sheet paired bands · rules · no holes Student Profiles documents and hours. Placement Requests on At a Glance.
Is it five rows or fewer inside another component? Inline rows paired bands only Placement Capacity by service line. A summary list inside a KPI card.
The boundary that matters most

A row that exists to be acted on is not a table row. It is a slip, and it belongs on a clipboard. Section 04 shows the difference.

02 · Same data, three levels

Interviews Focus Table View, rendered at each level

Identical rows and columns. Only the sheet chrome changes. Sorting and row expansion work at every level, so nothing functional is traded away by stepping down.

03 · The invariants

These hold at all three levels

The holes are the least important part of the canon. These eight rules are what will make a table on At a Glance feel like a table in Student Profiles.

04 · The boundary

A printout row is read. A slip is decided.

Both hold a person and a status. The difference is what you do next. If the row carries a decision the user makes, it is a slip on a board, and it keeps the clipboard language of Review & Release. If the row is a record, it is a printout row.

Printout row

Read, sorted, exported, expanded for detail. Actions, if any, open something elsewhere.

Clipboard slip

Carries a decision. Release, snooze, dismiss. Never sorted, never exported, never a column in a grid.
